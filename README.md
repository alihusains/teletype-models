# teletype-models

Verbatim, unmodified re-hosts of upstream access-gated audio model repositories, published so [Teletype](https://github.com/alihusains/teletype) can download models unattended (the app stores SHA-256s and verifies every file).

Every model is under a permissive license whose terms permit redistribution; see each release's `LICENSE` and `NOTICE.md`. Files are bit-identical to upstream — always verify against the release `SHA256SUMS`.
